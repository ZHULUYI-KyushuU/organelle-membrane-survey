# 细胞器膜：以酵母为模型的跨学科文献调研

为撰写一部中文学术教科书《细胞器膜：以酵母为模型的跨学科视角》所做的文献调研。覆盖酵母（以 *Saccharomyces cerevisiae* 为主，兼顾 *S. pombe*、*Pichia*、*Yarrowia* 等）各细胞器膜的生物学，以及物理学、数学、计算机科学、演化、医学、合成生物学、科学史与哲学视角。

## 从哪里读起

- `00_总报告_细胞器膜跨学科调研.md`：总报告。含一句话结论、跨学科总框架（"四本账"）、分部综述、建议的教科书目录、100 篇必读、开放问题总表、已知缺口与局限。
- `A01`–`E04`：40 个主题章的文献综述，每章末附该章全部文献表（含 DOI 链接）。
- `文献总表.md` / `文献总表.csv`：全部文献条目。

## 规模

40 章，5880 条文献条目，去重后 3783 篇（DOI），其中 5778 条附英文摘要。

## 方法

1. 每章三路检索：经典里程碑与综述、Europe PMC / CrossRef / OpenAlex 系统检索、交叉学科或酵母锚定检索。
2. 确定性脚本核验（`_data/_scripts/verify_candidates.py`）：按 DOI 查 CrossRef，题名相似度、第一作者与年份一致才通过；不符则按题名检索订正，找不到即剔除；拒收图表、数据集、会议摘要与勘误类记录；再从 Europe PMC / CrossRef / OpenAlex / Semantic Scholar 取摘要与被引数。
3. 章节综述只允许引用已核验文献，文献表由脚本生成。
4. 完整性检查、物理/数学/计算机三位评议人提出跨学科框架、一位评审打分，最后写总报告。

检索、写作与评议由 AI 代理完成，核验由脚本完成。

## 局限

- 所有判断只依据题名与摘要，未读全文；写作前请阅读核心论文原文。
- 文献偏向 *S. cerevisiae*；非英文文献与专著基本未收。
- 被引数来自 Europe PMC，部分来自 OpenAlex 或 Semantic Scholar，口径不一。
- 已知缺口（孢子形成与交配融合、磷脂降解、蛋白脂质修饰、离子与金属稳态、质膜信号、细胞壁、线粒体蛋白输入）见总报告第 8 节。

## 数据文件

- `_data/<章>.json`：每章已核验文献（题名、作者、年份、期刊、DOI、PMID、类型、中文发现、重要性、被引数、核验状态；英文摘要仅保留在本地版本）。
- `_data/_index.md`：全书章节索引；`_data/_gaps.json`：完整性检查结果。
- `_data/_scripts/`：核验、卡片、文献表与统计脚本（Python 标准库）。

公开版本的 JSON 不含英文摘要（版权归原出版方）；需要时可按 DOI 从 Europe PMC 获取。
